## What I've Built

### [Bazario Support AI](https://github.com/Mahiisss/bazario-support-ai) &nbsp;·&nbsp; `Python` `CrewAI` `FAISS` `Groq` `React`
Multi-agent RAG system that resolves e-commerce support tickets using 5 sequential agents — triage, retrieval, writing, compliance review, and escalation. Three independent hallucination-prevention layers ensure every claim is grounded in policy. Full citations, REST API, and a React dashboard with live agent progress.

---

### [AI Pipeline Orchestrator](https://github.com/Mahiisss/AI-Pipeline-Orchestrator) &nbsp;·&nbsp; `FastAPI` `React Flow` `n8n`
Visual DAG-based workflow builder with Kahn's Algorithm cycle detection, a node-by-node execution engine, and dual trigger modes — manual UI and n8n webhook. Node types include Transform, Math, API, Condition, and Output — with data flowing automatically between nodes.

---

### [KristalBall — Military Asset Management](https://github.com/Mahiisss/military-asset-management) &nbsp;·&nbsp; `Node.js` `React` `SQLite` `JWT`
Full-stack system for tracking military assets across bases — purchases, transfers, assignments, expenditures. Real-time inventory via strict stock formula logic. JWT-based RBAC with three roles.

```
Stock = Purchased + Transferred In − Transferred Out − Assigned − Expended
```

## How I Think About Systems

```
01  Data flow should be explicit and traceable end to end
02  Failure modes are designed, not discovered in production
03  ML belongs in the pipeline, not bolted on after
04  Every model output that reaches a user should be verifiable
05  Async where it matters, sync where it's clearer
06  Build for the edge case, not just the happy path
```
