## What I've Built

### [Bazario Support AI](https://github.com/Mahiisss/bazario-support-ai) &nbsp;·&nbsp; `Python` `CrewAI` `FAISS` `Groq` `React`
Multi-agent RAG system that resolves e-commerce support tickets using 5 sequential agents — triage, retrieval, writing, compliance review, and escalation. Built with zero hallucination tolerance via 3 independent verification layers. Every claim in the final response is traceable to a specific policy chunk ID.

---

### [AI Pipeline Orchestrator](https://github.com/Mahiisss/AI-Pipeline-Orchestrator) &nbsp;·&nbsp; `FastAPI` `React Flow` `n8n`
Visual DAG-based workflow builder with Kahn's Algorithm cycle detection, a node-by-node execution engine, real-time logging, and dual trigger modes — manual UI button and n8n webhook. Inspired by Airflow and n8n, built from first principles.

---

### [KristalBall — Military Asset Management](https://github.com/Mahiisss/military-asset-management) &nbsp;·&nbsp; `Node.js` `React` `SQLite` `JWT`
Full-stack system for tracking military assets across bases — purchases, transfers, assignments, expenditures. Real-time inventory via a strict stock formula. JWT-based RBAC with three roles: Admin, Base Commander, Logistics Officer.

```
Stock = Purchased + Transferred In − Transferred Out − Assigned − Expended
```
