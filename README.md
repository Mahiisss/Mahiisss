## Featured Projects

### [Bazario Support AI](https://github.com/Mahiisss/bazario-support-ai) &nbsp;`Python` `React`
5-agent sequential RAG pipeline for e-commerce ticket resolution. Three independent hallucination-prevention layers — retrieval grounding, mandatory citation format, and independent compliance review. Every claim in the final response is traceable to a specific policy chunk ID. 25,000+ words of policy documentation indexed across 64 FAISS chunks.

`CrewAI` `FAISS` `LangChain` `Groq · Llama 3.3 70B` `Flask REST API` `Pydantic v2`

---

### [AI Pipeline Orchestrator](https://github.com/Mahiisss/AI-Pipeline-Orchestrator) &nbsp;`Python` `JavaScript`
Visual DAG workflow builder with Kahn's Algorithm cycle detection and a node-by-node execution engine. Data flows automatically between Transform, Math, API, Condition, and Output nodes. Dual trigger modes: manual UI button and n8n webhook. Inspired by Airflow and n8n, built from first principles.

`FastAPI` `React Flow` `Zustand` `n8n` `Pydantic` `httpx`

---

### [KristalBall — Military Asset Management](https://github.com/Mahiisss/military-asset-management) &nbsp;`TypeScript` `JavaScript`
Full-stack logistics system for tracking assets (vehicles, weapons, ammunition) across military bases. Real-time inventory via strict formula. JWT-based RBAC with Admin, Commander, and Logistics Officer roles. Deployed on Render + Vercel.

```
Stock = Purchased + Transferred In − Transferred Out − Assigned − Expended
```

`Node.js` `Express` `React` `SQLite` `JWT · bcryptjs`

## Engineering Principles

```
01  Data flow should be explicit and traceable end to end
02  Failure modes are designed, not discovered in production
03  ML belongs inside the pipeline, not bolted on after
04  Every model output that reaches a user should be verifiable
05  Async where it matters, sync where it's clearer
06  Build for the edge case, not just the happy path
```
